## Operaciones matemáticas en Python

Python usa operadores para realizar cálculos:

- `+` para sumar.
- `-` para restar.
- `*` para multiplicar.
- `/` para dividir.
- `**` para calcular una potencia.

Por ejemplo:

```python
resultado = (10 + 5) * 2**3
print(resultado)
```
