## Monitoreo de temperatura

El sistema que monitorea las salas principales está fallando. Algunas se enfrían demasiado y otras aumentan peligrosamente su temperatura.

Debes arreglar el monitoreo. El sistema recibe temperaturas en Celsius, pero clasifica sus niveles usando Fahrenheit.

La conversión es:

```python
fahrenheit = (celsius * 1.8) + 32
```

Los rangos en Fahrenheit son:

- Menor o igual a `28.4` → `"muy bajo"`.
- Mayor a `28.4` y menor o igual a `53.6` → `"bajo"`.
- Mayor a `53.6` y menor o igual a `64.4` → `"medio"`.
- Mayor a `64.4` → `"alto"`.
