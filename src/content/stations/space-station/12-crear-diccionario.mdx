## Diccionarios

Un diccionario guarda pares de **llave** y **valor**:

```python
modulos = {
    "PS004": 80,
    "PS014": 120,
}
```

Puedes obtener un valor con su llave:

```python
print(modulos["PS004"])
```

## Tu misión
