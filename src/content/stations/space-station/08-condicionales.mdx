## Protocolo de seguridad

Los tripulantes deben reparar una filtración de altas temperaturas provocada por un panel solar averiado.

Antes de enviarlos, activa el sistema de seguridad para que solo entre personal con el equipamiento correcto.

<StationCallout title="🛡️ Reglas de ingreso">
  Un tripulante puede entrar solo si tiene credencial permitida (`True`) y un traje con resistencia `"Alta"`.
</StationCallout>

Van a ingresar tres tripulantes:

- Tripulante uno: credencial `True` y resistencia `"Alta"`.
- Tripulante dos: credencial `True` y resistencia `"Baja"`.
- Tripulante tres: credencial `False` y resistencia `"Alta"`.

## Condicionales

`if` ejecuta código cuando una condición se cumple:

```python
if acceso == True:
    return True
```

Puedes exigir que dos condiciones se cumplan a la vez con `and`:

```python
if acceso == True and resistencia == "Alta":
    return True
else:
    return False
```

## Tu misión

Reemplaza los valores `None` por los valores correctos. No cambies el resto de la función.

<StationDisclosure title="Pista">
  La primera condición revisa si la credencial permite el acceso.

  La segunda revisa si el traje tiene resistencia `"Alta"`.

  Ambas condiciones deben cumplirse para devolver `True`.
</StationDisclosure>
