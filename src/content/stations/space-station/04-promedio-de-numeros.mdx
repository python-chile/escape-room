## Listas en Python

Una lista agrupa varios valores entre corchetes `[]`, separados por comas:

```python
numeros = [1.2, 2, 3.5, 4]
```

Python incluye el módulo `statistics`, que tiene la función `mean()` para calcular promedios:

```python
import statistics

promedio = statistics.mean([10, 20, 30])
print(promedio)
```
