## Unir textos con `.join()`

`.join()` une todos los elementos de una lista usando el texto que está antes del punto como separador.

```python
palabras = ["Hola", "mundo"]
separador = " "

respuesta = separador.join(palabras)

print(respuesta)
```

Salida:

```text
Hola mundo
```
