## Paneles solares inestables

Los paneles solares de la estación muestran lecturas inestables.

Para mantener la energía funcionando, debes recalibrar la temperatura aplicando esta fórmula:

```text
((1.23 + 2.34) / (1 + (43 / 2))) + (3 * 2**1.5)
```

## Números decimales

En Python los números decimales usan un punto, no una coma:

```python
temperatura = 33.5
```

La potencia se escribe con dos asteriscos:

```python
resultado = 2**3
```
