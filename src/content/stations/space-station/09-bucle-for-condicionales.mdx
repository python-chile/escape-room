## Tu misión

Debes:

- Recorrer la lista `objetos`.
- Verificar si cada objeto no está en `reparados`.
- Agregarlo a `por_reparar`.

## `for`, `if` y `.append()`

```python
for objeto in objetos:
    if objeto not in reparados:
        por_reparar.append(objeto)
```

<StationDisclosure title="Pista">
  `not in` verifica que un valor no exista en una lista.

```python
if objeto not in reparados:
```

`.append()` agrega un elemento al final de una lista.

```python
por_reparar.append(objeto)
```

</StationDisclosure>
