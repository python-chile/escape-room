## Transformar texto

`.upper()` convierte un texto a mayúsculas:

```python
palabra = "asteroide escila"
print(palabra.upper())
```

`.lower()` convierte un texto a minúsculas:

```python
palabra = "METEORITO ARLONG"
print(palabra.lower())
```

Para saber si un texto contiene otro texto, usa `in`:

```python
if "asteroide" in palabra:
    print("Objeto detectado")
```
