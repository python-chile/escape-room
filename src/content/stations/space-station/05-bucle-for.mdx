## El bucle `for`

`range(a, b)` crea una secuencia de números que comienza en `a` y termina antes de `b`.

```python
range(1, 5)
```

produce los números `1`, `2`, `3` y `4`.

Un bucle `for` repite código para cada número de una secuencia:

```python
for numero in range(1, 5):
    print(numero)
```

## Tu misión

No cambies el bucle. Solo asigna los límites correctos a `a` y `b`.

<StationDisclosure title="Pista">
  `range()` no incluye el valor final.

  Si quieres llegar hasta `1000`, el segundo valor debe ser `1001`.

  ```python
  range(1, 1001)
  ```
</StationDisclosure>
