## Índices de una lista

Las listas guardan varios valores:

```python
lista = [1, 2, 3, 4]
```

Los índices positivos comienzan en `0`:

```python
lista[0]  # 1
lista[2]  # 3
```

Los índices negativos cuentan desde el final:

```python
lista[-1]  # 4
lista[-2]  # 3
```
