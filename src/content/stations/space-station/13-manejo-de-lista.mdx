## Obtener un sufijo

Los últimos cuatro caracteres de un texto se obtienen con:

```python
sufijo = archivo[-4:]
```

Por ejemplo:

```python
archivo = "lab_ps01"

print(archivo[-4:])
```

Salida:

```text
ps01
```

## Tu misión

Crea un diccionario vacío y recorre la lista `archivos`.

- Si el sufijo todavía no existe, crea una lista con el archivo.
- Si ya existe, agrega el archivo a su lista.

<StationDisclosure title="Pista">
  La estructura principal es:

  ```python
  respuesta = {}

  for archivo in archivos:
      sufijo = archivo[-4:]

      if sufijo not in respuesta:
          respuesta[sufijo] = [archivo]
      else:
          respuesta[sufijo].append(archivo)
  ```
</StationDisclosure>
