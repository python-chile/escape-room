## Ordenar una lista

La función `.sort()` ordena una lista de menor a mayor:

```python
numeros = [8, 3, 5]
numeros.sort()

print(numeros)
```

Salida:

```text
[3, 5, 8]
```

Puedes obtener:

```python
numeros[0]   # Primer elemento
numeros[-1]  # Último elemento
```

## Valor central

La lista tiene seis elementos. Como tiene una cantidad par, el valor central es el promedio entero de los dos valores que están al medio.

```python
valor_central = (numeros[2] + numeros[3]) // 2
```

`//` divide y conserva solo la parte entera.

## Tu misión

Ordena `coordenadas` y crea una lista llamada `respuesta` con este formato:

```python
[menor, valor_central, mayor]
```
