## Bucle `for` anidado

Un bucle anidado es un `for` dentro de otro `for`.

Por cada valor de `x`, se recorren todos los valores de `y`:

```python
for x in coordenadas:
    for y in coordenadas:
        print(x, y)
```

Puedes agregar una tupla a una lista con `.append()`:

```python
respuesta.append((x, y))
```
