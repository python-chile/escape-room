## ¿Cómo se cargan datos en Python?

En Ciencia de Datos usamos `pandas` para trabajar con archivos y tablas.

Los pasos típicos son:

1. Importar la librería:

   ```python
   import pandas as pd
   ```

2. Leer un archivo CSV:

   ```python
   pokemon_data = pd.read_csv("/pokemon.csv")
   ```

3. Mostrar las primeras filas:

   ```python
   print(pokemon_data.head())
   ```

<StationDisclosure title="Pista">
  En esta misión el archivo ya está preparado dentro del laboratorio.

Debes usar exactamente esta ruta:

```python
url = "/pokemon.csv"
```

Después carga los datos:

```python
df = pd.read_csv(url)
```
