## Contar y graficar datos

Para contar los Pokémon según su tipo principal, usa:

```python
conteo = df["Type 1"].value_counts()
```

Esto produce una tabla donde cada tipo tiene su cantidad de Pokémon.

Para crear un gráfico de barras:

```python
conteo.plot(kind="bar")
```

PySchool detecta el gráfico y lo muestra automáticamente debajo de la salida. No necesitas usar `plt.show()`.
