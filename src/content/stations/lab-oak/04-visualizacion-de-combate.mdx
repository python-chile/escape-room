## Tu misión

1. Elige dos estadísticas de combate en `col_x` y `col_y`.
2. Crea un gráfico de dispersión.
3. Crea una columna llamada `suma` con ambas estadísticas.
4. Muestra los cinco Pokémon con mayor suma.
5. Guarda en `respuesta` el nombre del Pokémon con la mayor suma.

Puedes elegir entre:

```python
"Attack"
"Defense"
"HP"
"Speed"
```

<StationDisclosure title="Pista">
  Puedes comenzar con:

```python

col_y = "Defense"
color = "orange"
```

Para obtener el Pokémon con mayor suma:

```python
respuesta = df.loc[df["suma"].idxmax(), "Name"]
```
