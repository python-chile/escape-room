## Explorar datos con pandas

Con `pandas` puedes obtener información general de un conjunto de datos:

- `.info()` muestra columnas, tipos de datos y cantidad de registros.
- `.describe()` muestra estadísticas de las columnas numéricas.

```python
df.info()
df.describe()
```

<StationDisclosure title="Importante">
  `df.info()` muestra la información directamente en la consola y devuelve `None`. Por eso se ejecuta solo.

En cambio, `df.describe()` devuelve una tabla, que puedes guardar en una variable:

```python
desc = df.describe()
print(desc)
```

</StationDisclosure>
