## Agrupar y calcular promedios

`groupby()` agrupa los datos según una columna. Después, `mean()` calcula el promedio de cada grupo.

```python
promedio = df.groupby("Type 1")[
    ["HP", "Attack", "Defense", "Speed"]
].mean()
```

Para encontrar el mayor valor de una columna usa `.idxmax()`:

```python
tipo_mas_ataque = promedio["Attack"].idxmax()
```

Para encontrar el menor, usa `.idxmin()`:

```python
tipo_menos_defensa = promedio["Defense"].idxmin()
```
